#### How to run the application

pull the entire repository or copy the file

The file should be in the `GOPATH`

Run `go run main.go`

Follow the prompts in the menu and enter a choice 

```

1. Insert value in linked list (rear end)
2. Display linked list
3. Deleting from begining
4. Delete from last node
5. Deleting from specific location
6. insert at specific location
7. insert at begining (front end)
8. Update node
9. Update similar values
10. Display count
11. Update multiple values with indexes
12. Delete multiple values with indexes
13. Get multiple values with indexes
14. Delete Similar values
15. Indepotency
0. Exit

```
